# Почему не вендорить компоненты

## Рассмотренная альтернатива

Скачать исходники лучших компонентов в `assets/` скилла — тогда всё работает
офлайн и мгновенно.

## Отвергнуто

**Протухание.** React Bits, Magic UI, paper-shaders обновляются еженедельно
(последние push-и на 2026-09-17 — тот же день). Вендоренная копия через месяц
врёт про API, через полгода — про зависимости.

**Лицензии.** `MIT + Commons Clause` у React Bits/Vue Bits/Svelte Bits запрещает
продавать сами компоненты. Хранить их копию в личном тулчейне — серая зона,
которой незачем существовать.

**Объём.** Только react-bits — 688 элементов. Сорок источников такого размера
превращают скилл в монорепозиторий чужого кода.

**Это уже решено.** [[shadcn-registry-protocol]] отдаёт актуальный исходник за
один curl. Кеш поверх сети, которая и так быстрая, — лишняя сущность.

## Что храним вместо

Указатель + проверенную команду + суждение «зачем этот источник нужен».
Три вещи, которые сеть не отдаёт и которые не протухают так быстро, как код.

Инвариант №2 в [[../../references/maintaining.md|maintaining.md]].
