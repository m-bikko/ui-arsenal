# Двухслойный реестр

[[sources-json]] держит **42 курируемых** источника. Скрипт [[search-py]] при этом
умеет искать ещё и по **живому** каталогу — `ui.shadcn.com/r/registries.json`,
354+ реестра с health-скорами.

## Почему не один слой

**Только курируемый** — протухнет. Экосистема растёт быстрее, чем кто-либо
успевает вручную добавлять записи. На 2026-09-17 в живом каталоге 354 реестра;
курировать их все бессмысленно.

**Только живой** — теряет самое ценное. В живом каталоге нет:

- мнения («aceternity — когда бриф говорит "дорого выглядит"»);
- способов доступа кроме shadcn CLI (нет llms.txt, git clone, gh-api, MCP);
- источников вне экосистемы shadcn — Codrops, Uiverse, Three.js, Vanta, Rive,
  LottieFiles, Spline, Animista, Open Props, awesome-списки;
- предупреждений: bot-walls, rate limits, лицензионные ловушки.

## Правило разделения

Механически обнаружимое → живой слой.
Требующее суждения или недоступное через каталог → курируемый слой.

Источник, который находится через `--live`, попадает в курируемый только если
у него есть **сильное мнение**, **неочевидный способ доступа** или **gotcha**.
Иначе курируемый слой раздувается и перестаёт быть полезным фильтром.

Инвариант записан в [[../../references/maintaining.md|maintaining.md]], пункт 4.
