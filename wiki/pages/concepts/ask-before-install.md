# Правило «сначала спроси»

Источники из [[sources-json]] тянут `three`, `gsap`, `ogl`, `motion`,
`@splinetool/runtime`, WebGL-рантаймы. Это bundle size, производительность на
слабых устройствах и доступность.

## Граница

**Бесплатно и без вопросов:** искать, читать исходники, сравнивать варианты,
цитировать код, объяснять что как устроено. Чтение ничего не ломает.

**Только после явного «да»:** добавление зависимости, `npx shadcn add`,
`npm i`. Спрашивать конкретно — с именем пакета и весом:

> «`@react-bits/MetaBalls-TS-TW` подходит, ему нужен `ogl` (~30 КБ).
> Ставим? Или сделать на CSS без новой зависимости?»

**Не переспрашивать:** если пользователь сам назвал технологию — это согласие.

**При отказе:** решать через CSS / SVG / `prefers-reduced-motion`.

## Связь с глобальным правилом

Дублирует секцию `🎨 Claude Design Skillstack` в `~/.claude/CLAUDE.md`. Там то же
правило для 22 скиллов 3D/WebGL. Пересечение осознанное: оба набора трогают одни
и те же тяжёлые зависимости, и правило должно срабатывать независимо от того,
через какой скилл агент туда пришёл.
